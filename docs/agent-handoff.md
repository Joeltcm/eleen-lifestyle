# Plantilla de relevo

Pega y completa este bloque al terminar una tarea para que otro agente pueda continuar sin reconstruir el contexto.

```md
## Relevo

- Objetivo terminado:
- Commit / PR:
- Archivos principales modificados:
- Verificación ejecutada:
- Despliegue:
- Variables o migraciones requeridas:
- Pendiente / riesgo conocido:
- Próximo paso recomendado:
```

No incluyas secretos, contraseñas, tokens, IDs privados ni resultados completos de comandos que puedan mostrarlos.
